외근 영수증 증빙 - 웹사이트 올리는 방법

이 폴더의 파일 15개를 그대로 웹 서버에 올리면 됩니다. (하위 폴더 없음)
반드시 https 주소여야 합니다. (휴대폰 '보내기'와 임시 저장 기능이 https에서만 동작)

[이미 GitHub에 올린 저장소를 고치는 경우]
1. 저장소 첫 화면(Code)에서 Add file → Upload files
2. 이 폴더의 파일 15개를 모두 선택해서 끌어다 놓기 → Commit changes (같은 이름은 새 파일로 바뀜)
3. 예전에 올린 ocr, lib 폴더는 이제 필요 없습니다. (남아 있어도 문제는 없음)
4. 1~3분 뒤 휴대폰에서 사이트를 새로고침. 상단에 '영수증 읽기 준비됨'이 뜨면 정상입니다.
   * 계속 예전 화면이 보이면 휴대폰 브라우저를 완전히 닫았다가 다시 여세요.

[처음 GitHub Pages로 올리기 - 무료, 약 5분]
1. github.com 에 로그인(계정이 없으면 가입)
2. 오른쪽 위 + → New repository → 이름 예: receipt → Public 선택 → Create repository
3. "uploading an existing file" 클릭 → 이 폴더의 파일 15개를 모두 선택해 끌어다 놓기 → Commit changes
   * 폴더째 끌어다 놓지 말고, 폴더를 열어 안의 파일들을 선택하세요.
4. 저장소의 Settings → Pages → Source: "Deploy from a branch", Branch: main / (root) → Save
5. Actions 탭의 작업이 초록 체크가 되면 Settings → Pages 맨 위에 사이트 주소가 나옵니다.
   (예: https://<내 아이디>.github.io/receipt/) 이 주소를 동료에게 공유하세요.
   * 저장소는 공개되지만 프로그램 코드만 있고, 영수증 등 개인 데이터는 전혀 올라가지 않습니다.

[글자 인식이 안 될 때]
화면 위 '글자 인식을 불러오지 못함' 표시를 누르면 원인이 나옵니다.
'○○ 파일이 서버에 없어요'라고 나오면 그 파일을 다시 올리세요.

[휴대폰 홈 화면에 추가]
아이폰 사파리: 공유 버튼 → 홈 화면에 추가 / 안드로이드 크롬: 메뉴 → 홈 화면에 추가
